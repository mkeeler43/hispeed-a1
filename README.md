# Hispeed A1 Trainer

Practice page for the Hispeed A1 German course (HS 26). It covers weeks 1 to 10.
Each stop mixes grammar and vocabulary. The questions climb from flashcards to writing your own sentences.

Two exam tabs sit next to the weeks:

- Prüfung: Gespräch is a conversation partner for the oral exam. A practice bot asks the course and exam questions and checks each answer. You can also paste your own Anthropic API key to talk with Claude instead. The key stays in your browser.
- Prüfung: Grammatik is an overview of all grammar so far. Every section has a practice round.

Open it here: https://mkeeler43.github.io/hispeed-a1/

Scores are saved only in your own browser.
